## 📊 Google Sheets (formato Pedilo / BR Burgers)

La web lee las hojas **`productos`** y **`configuracion`** del mismo Excel que usa Pedilo.

Guía completa: **`GOOGLE_SHEETS_TEMPLATE.md`**

1. Importá `DOCS PAGINA PEDILO.SHOP.xlsx` a Google Sheets  
2. Compartí como **Lector**  
3. Pegá el ID en `index.html` → `PEDILO_SHEET_ID`

## 💡 TIPS & TRUCOS

### Guardar un carrito sin enviar
→ Cierra la pestaña, el carrito se guarda automáticamente

### Crear un link compartible del pedido
→ Copia el link que se genera cuando haces click en "Enviar"

### Compartir solo ciertos productos
→ Usa la variable "ocultar" en Google Sheets

### Cambiar precios rápidamente
→ Edita Google Sheets (si lo configuraste) y actualiza
