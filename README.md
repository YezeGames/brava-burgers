# Brava Burgers — repo local

**Código de producción (Vercel / GitHub):** carpeta [`BravaBurgers/`](BravaBurgers/).

No dupliques `admin/`, `api/`, `lib/` ni `supabase/` en la raíz de este clone: solo edita dentro de `BravaBurgers/`.

Deploy: push a `main` en https://github.com/YezeGames/brava-burgers → https://brava-burgers.vercel.app

Supabase (una vez): `BravaBurgers/supabase/BRAVA_SUPABASE_RUN_ONCE.sql` (incluye `snapshot_json` para historial de cierre).
